## 🚀 Go Live (When Ready)

## 📞 Need Help?

### Common Issues:

**Menu not working?**
- Clear browser cache
- Check if `script.js` is in same folder as `index.html`

**Images not showing?**
- Check internet connection (placeholder images load from web)
- Images will work offline after first visit

**Booking form not submitting?**
- It's working! Check browser console (F12)
- To send emails, see README.md for backend setup

**Mobile menu stuck open?**
- Refresh the page
- Click outside the menu area
